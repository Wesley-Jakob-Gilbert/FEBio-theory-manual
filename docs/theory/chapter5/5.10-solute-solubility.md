# 5.10 Solute Solubility {: #sec:Solute-Solubility }

Solubility constitutive equations provide a relation for $\tilde{\kappa}$ as a function of solid matrix strain and effective solute concentrations.

## Constant Solubility {: #subsec:Constant-Solubility }

For this material model, $\tilde{\kappa}$ is constant.
