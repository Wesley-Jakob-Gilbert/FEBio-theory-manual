# 3.7 The Graphics Toolbar {: #subsec:mylabel15 }

The _Graphics Toolbar_ can be found at the bottom of the Graphics View and provides the user with some information regarding the Graphics View and some additional tools that affect the current selection.

![pivot](figs/pivot.png)This toggles the _pivot lock_ mode. The pivot is the point that serves as the origin for transformations. Usually it is calculated automatically based on the current selection, but by clicking this button, the user can lock the pivot and edit it coordinates manually in the next three panels.

![snaptogrid](figs/snaptogrid.png)When the _snap-to-grid_ button is checked, a selection can only be translated in increments of the current grid spacing.

![snaptonode](figs/snaptonode.png)This option allows users to position the 3D cursor at nodes of the geometry.

![toggle_visible](figs/toggle_visible.png)This toggles all visible objects and parts. (Or elements when in mesh selection model.)

![zoom_select](figs/zoom_select.png)Zoom to the current selection.

![zoom_all](figs/zoom_all.png)Zoom to the extents of the current model.

![show_mesh](figs/show_mesh.png)Toggle Mesh Lines
