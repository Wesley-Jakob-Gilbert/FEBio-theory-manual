# 3.3 The Main Tool Bar {: #subsec:mylabel13 }

Some of the menu items can also be accessed through the Main Tool bar. The Main Tool bar offers the following options.

![new](figs/new.png)Start a new FEBio Studio model.

![open](figs/open.png)Open a saved FEBio Studio model.

![save](figs/save.png)Save the current FEBioStudio model.

![snapshot](figs/snapshot.png)Saves a screenshot to file.

![teapot](figs/teapot.png) Creates a ray-traced rendering of the active model.
