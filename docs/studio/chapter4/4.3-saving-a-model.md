# 4.3 Saving a model {: #subsec:saving }

A model can be saved from the **File** → **Save** or **File** → **Save as** menus. The former can be used to save the file to the same location as it was loaded. For new models that have not been saved yet, this will execute the **File** → **Save as** command on the first attempt to save the model. The **File** → **Save as** menu allows the user to select a file name for storing the model.
