# 14.2 The Post Menu {: #subsec:mylabel3 }

The post menu allows the user to set many of the options that effect what is being displayed.

- _Plane Cut -_ add a clipping plane to the model.

- _Mirror plane_ - adds a mirror plane to the model that mirrors the geometry.

- _Vector plot -_ adds a vector plot object to the model.

- _Tensor plot_ - adds a tensor plot object to the model.

- _Isosurface plot -_ adds an isosurface plot object to the model.

- _Slice plot -_ adds a slice plot object to the model.

- _Displacement map -_ add a displacement map to the model. (Note that for standard FEBio plotfiles, a displacement map is automatically added to the model when loading the file.)

- _Streamlines plot_ - adds a stream line plot, which can be useful for visualizing flow fields.

- _Particle flow plot_ - adds a particle flow plot, which shows particles flowing in a vector field.

- _Volume flow plot_ - adds a volume flow plot, which renders a volumetric “fog” whose density is proportional to the selected field value.

- _Point probe_ - adds a point probe, which allows users to track a location on a model and sample the current value.

- _Curve probe_ - adds a curve probe, which tracks and samples the value along a user-defined curve.

- _Ruler_ - can be used to track relative position and distance between two nodes of the mesh.

- _Muscle Path_ - Defines a geodesic curve between two points, i.e. a shortest-path that wraps around geometry. Can be used as a simple representation of a muscle and allows calculation of departure points and moment arms.

- _Vector glyph_ - Can be used to show vector data at particular points in the model. (E.g. to show velocity, acceleration, or force on a rigid body.)

- _Helical axis_ - Calculates the location and orientation of the helical axis of a rigid body and displays it in the Graphics View.

- _Plot group_ - Create a new plot group in the model tree. If a plot group is selected in the model tree when adding a new plot object, the plot object will be added to the plot group. Post model items can also be moved between groups by right-clicking on the item and select “Move to group” from the popup menu.

- _Image slicer_ - adds an image slicer, which shows a slice from a 3D image stack.

- _Volume renderer_ - adds a volume renderer to the Graphics View, which displays a 3D rendering of a image stack.

- _Image isosurface_ - renders an isosurface of a 3D image stack.

- _New Graph -_ opens a new graph window.

- _Scatter plot_ - Opens a new Graph window that shows a scatter plot of the selected data.

- _Summary -_ provides 2D plots of minimum, maximum and average of the data fields.

- _Statistics -_ displays a bar chart of the currently displayed data.

- _Integrate -_ shows the integration tool.

- _Integrate surface_ - Shows the _Integrate Surface_ tool, which performs an integration of the currently selected datafield multiplied by the local normal. The components of the resulting vector field are shown as three individual line plots.

- _Import points -_ This tool imports point data that can be superimposed on the model. Enter a name for the point data, select the source file, and click Apply.

- _Import lines -_ This tool imports line data that can be superimposed on the model. Enter a name for the line data, select the source file, and click Apply.
