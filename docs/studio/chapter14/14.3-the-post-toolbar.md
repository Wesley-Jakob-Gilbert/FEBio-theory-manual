# 14.3 The Post Toolbar {: #subsec:mylabel5 }

The _Post_ toolbar offers various shortcuts to the Post menu items.

![back](figs/back.png)Return to the first time step

![prev](figs/prev.png)Step back by one step

![play](figs/play.png)Start (and stop) the animation

![next](figs/next.png)Step forward by one step

![forward](figs/forward.png)Go to the last time step

![properties](figs/properties.png)Open the time dialog box

![colormap](figs/colormap.png)Activate the contour plot

![cut](figs/cut.png)Adds a plane cut plot to the model

![mirror](figs/mirror.png)Adds a mirror plane to the model

![vectors](figs/vectors.png)Adds a vector plot to the model

![tensor](figs/tensor.png)Adds a tensor plot to the model

![isosurface](figs/isosurface.png)Adds a isosurface plot to the model

![post_slice](figs/post_slice.png)Adds a slice plot to the model

![streamlines](figs/streamlines.png)Adds a stream line plot to the model

![particle](figs/particle.png)Adds a particle flow plot to the model

![imageslice](figs/imageslice.png)Adds an image slicer to the model

![volrender](figs/volrender.png)Adds a 3D volume renderer to the model

![marching_cubes](figs/marching_cubes.png)Adds an isosurface rendering of a 3D image stack.

![chart](figs/chart.png)Opens a new graph window

![integrate](figs/integrate.png)Opens the Integrate window
