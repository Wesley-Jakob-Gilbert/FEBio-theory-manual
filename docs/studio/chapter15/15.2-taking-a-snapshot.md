# 15.2 Taking a snapshot

To take a snapshot of the current Graphics View push the _snapshot_ button on the toolbar. A standard _Save_ dialog box appears and the desired filename can be entered or selected. Images can be saved as BMP, TIFF or JPEG images. To only capture a part of the Graphics View, make sure the capture frame is active. To activate the capture frame, use the menu **View** → **Show Capture Frame**, or use the corresponding '0' (number zero) shortcut. The capture frame can be moved by dragging its border or resized by dragging the lower-right corner.
