# A.14 IDEAS

This is the file format of the I-DEAS software.

The IDEAS file reader will import the nodal coordinates and element connectivity. The following element types are supported:

- 11: rod element

- 21: linear beam

- 22: tapered beam

- 23: curved beam

- 24: parabolic beam

- 44: plane stress linear quadrilateral

- 91: linear triangular element

- 94: linear quadrilateral element

- 111: linear tetrahedral element

- 112: linear wedge element

- 113: 15-node wedge element

- 115: linear brick element

- 116: 27-node brick element

- 118: 10-node tetrahedron element
