# A.12 STEP

Step files are used to import CAD geometry. The STEP file reader is supported mostly through a third-party library, called OpenCascade[^A.12-fn1] and should be able to read a wide variety of STEP files.

The STEP file reader will import each solid part defined in the STEP file as a separate object.


[^A.12-fn1]: https://www.opencascade.com/
