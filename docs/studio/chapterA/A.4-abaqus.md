# A.4 ABAQUS {: #subsec:abaqus }

The following ABAQUS®keywords are supported in FEBioStudio.

- ELEMENT

- ELSET

- END PART

- END INSTANCE

- HEADING

- INCLUDE

- INSTANCE

- MATERIAL

- NFILL

- NGEN

- NODE

- NSET

- PART

- SURFACE

- SURFACE INTERACTION

The following element types are recognized.

- C3D8

- C3D6

- C3D4

- C3D10

- R3D4

- S4

- S3

- S3R

- R3DR
