# 7.4 Creating a Solute Table {: #subsec:mylabel23 }

Solutes may be included in several types of materials in FEBio, including biphasic-solute, triphasic, and multiphasic materials. A global table of solutes is created by accessing the **Physics** → **Solute Table** menu. When adding materials that include solutes (Section [Creating Geometry](../chapter5/5.1-creating-geometry.md#subsec:creating)), these may be selected from the solute table.
