# 17.5 Mirror Plane

The mirror plane allows users to mirror the geometry along one of the principal axis (X, Y, Z). To add a mirror plane, select the menu **Post** → **Mirror Plane**, or select the corresponding button on the post toolbar. The mirror plane defines the following options.

- _Mirror plane_ - Define the reflection direction.

- _Show plane -_ Show the mirror plane itself or not.

- _Transparency_ - Set the transparency of the mirror plane.

- _Offset_ - Defines a translation of the mirror plane.

To enable the mirror plane, check the check button next to the name field.
